# Angular

Example [Angular](https://angular.io/) app. Angular is a TypeScript framework from Google for building single-page web applications.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — Railpack build |
| Single-page application (SPA) | on |
| Project directory | `/` |
| Output directory | `/dist/app-example-angular/browser` |
| Install command | leave empty |
| Build command | leave empty |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run start

# build for production with minification
npm run build
```
