# Angular

Пример приложения [Angular](https://angular.io/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Static |
| Собрать проект перед публикацией | включено |
| Одностраничное приложение (SPA) | включено |
| Путь до директории проекта | `/` |
| Директория сборки | `/dist/app-example-angular/browser` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Angular кладёт готовые файлы в
`dist/app-example-angular/browser` — эту папку и публикуем.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в дев режиме с отслеживанием изменений
npm run start

# сборка для продакшн с минификацией
npm run build
```
